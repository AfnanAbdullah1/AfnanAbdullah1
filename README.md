### TrafficLight AI

A smart hybrid traffic-light control system combining computer vision, IoT hardware, and embedded control.

**Highlights**

- Customized YOLOv8 model for vehicle detection
- Dynamic green-light timing based on traffic density
- ESP32-WROOM intersection controller
- Three ESP32-CAM camera nodes
- HC-SR04 ultrasonic sensing for additional vehicle detection
- Flask dashboard with live camera streams and manual overrides
- Emergency-vehicle routing and remote access support
