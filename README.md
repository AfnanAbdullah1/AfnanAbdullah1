## 🚀 Featured Projects

### 🚦 [TrafficLight AI — Smart Traffic Control System](https://github.com/AfnanAbdullah1/TrafficLight_Ai)
> *A smart system that adjusts traffic lights automatically using computer vision and microcontrollers.*
- **Smart Timing:** Uses YOLOv8 to count vehicles in each lane and adjusts green light timers (5s to 10s) based on real traffic.
- **Hardware Setup:** Runs on an ESP32 board connected to 3 ESP32-CAM nodes and ultrasonic sensors.
- **Live Dashboard:** Created a Flask web interface to watch live video feeds, control lights manually, and open clear routes for ambulances.
- **Tags:** `YOLOv8` `ESP32` `Python` `OpenCV` `Flask` `IoT`

---

### ⚙️ [Real-Time Vibration Signal Analysis](https://github.com/AfnanAbdullah1/Real-Time-Vibration-Signal-Analysis-for-Mechanical-Systems)
> *Catching mechanical machine faults early before they break down.*
- **Gear Wear Analysis:** Tested and classified gear vibration signals across 6 different levels of wear and tear.
- **Anomaly Detection:** Wrote an algorithm that spots unusual vibration spikes and surface damage.
- **Predictive Maintenance:** Combined MATLAB signal processing with Python tools to make mechanical diagnosis automatic.
- **Tags:** `MATLAB` `Python` `Signal Processing` `Fault Diagnosis`
